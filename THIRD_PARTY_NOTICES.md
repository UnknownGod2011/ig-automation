# Third-party references

Logged-out Instagram metadata extraction follows the strategy and public query identifiers in yt-dlp's Instagram extractor. yt-dlp is released under the Unlicense: https://github.com/yt-dlp/yt-dlp/blob/master/LICENSE . The code here is a small independently implemented Worker-compatible extraction adapter, not a bundled Python runtime.

The optional Cobalt adapter implements its documented HTTP interface; it does not copy Cobalt's server implementation. A Cobalt instance must be self-hosted or used with the instance owner's permission.

Okramjimmy/Instagram-reels-downloader was investigated as requested. Its source was not copied into this project.
